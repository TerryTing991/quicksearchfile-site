Getting started

  1. Click Add Folder and choose one or more folders, including iCloud Drive folders.
  2. Click Build Index the first time. Document text and OCR are read in the background, with a progress bar.
  3. Enter a file name keyword, file type, content keyword, exclude keyword, or a combination, and click Search.
  4. Select a result to preview it on the right. Use the up and down arrows above the preview to move between matches for each keyword.

Click Update Index after files are added, removed, renamed, or changed. Adding or removing folders also marks the index as needing an update. With Pro, automatic index updates do this for you.

iCloud Drive and other synced folders: files stored only in the cloud need to be downloaded to your Mac before their text can be indexed.

Search tips

  • File Name searches file names. Extension filters by file type. Content searches inside documents. Exclude removes files whose content contains unwanted keywords.
  • Separate multiple keywords with spaces, line breaks, or commas. Multiple content keywords use AND logic, so every keyword must be found in the document.
  • Keywords of three or more letters or digits also match inside longer words, so 4401 finds PN-44017. Shorter keywords match whole words.
  • End a keyword with * to match words that start with it, such as ap* for apple and approval.
  • English searches can match common word variations, such as disc and discs. Chinese, Japanese, and Korean text is supported.
  • In a PDF preview, drag a box to zoom in on that area, up to 800%.
  • Right-click a result to Open, Open With, Reveal in Finder, Show Path, or Copy Path.

OCR for scanned PDFs and images

Text that already exists inside documents, including searchable PDFs, is read directly. OCR runs only on scanned pages and image files (JPG, PNG, HEIC, TIFF, BMP), so text in pictures can also be found. OCR is available on every plan and can be turned off in Settings.

Recognition quality depends on the image. Sharp, well-lit, straight scans work best. Very small print, handwriting, and low-resolution photos may be missed.

Plans and purchases

Basic is free with no time limit: up to 2 folders, one file name keyword, one content keyword, a file type filter combined with a keyword, and OCR.

Pro adds more folders, multi-keyword search (up to 3 content keywords), file-type-only search, exclude keywords, automatic index updates, and the command line tool. Pro is available as Monthly, Yearly, or Lifetime from the Plan screen in the app. There is no free trial.

  • Cancel or change a subscription: open the App Store, click your name, then Account Settings, and manage your subscriptions there. Apple handles all payments.
  • Refunds: request them from Apple at reportaproblem.apple.com.
  • New Mac or reinstall: sign in with the same Apple Account and click Restore Purchases on the Plan screen.

FAQ

Why doesn't a new file show up in results?

Click Update Index after files are added, removed, renamed, or changed. If the file is in iCloud Drive, make sure it's downloaded to your Mac. Pro can update the index automatically.

Why does a file appear without a highlight?

Matching words are highlighted when highlight information is available for that file. When a preview can't show the highlight, the matching lines are still shown under the result in the list.

Why can't I search a file type on its own?

In Basic, the Extension field works together with a file name or content keyword. File-type-only search is part of Pro.

Does Find Text change or move my files?

No. Find Text reads the folders you add to build its index and doesn't change your documents.

Where is my data stored?

The index and settings are stored on your Mac. Your files, document text, and search history are never uploaded. See the privacy policy.

Is Find Text the same app as Quick Search File?

No. They are separate apps with separate support. Find Text searches the words inside your documents on Mac. It was previously listed on the App Store as "Quick Search Files & Find Text".
