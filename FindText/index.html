How it works

Three steps, then just type.

Add folders

Choose the folders you want to search, including iCloud Drive folders. Find Text reads only what you add.

Build the index once

Document text and OCR are read in the background with a progress bar. The index stays on your Mac.

Type a word, press Return

Every file that contains it appears, with the match highlighted in the preview beside the results.

Features

Find the exact spot, not just the file.

Search inside documents, scans, and photos, then jump straight to each highlighted match.

See every match

Each keyword gets its own color and counter.

Matches are highlighted in the preview, and each keyword has a counter like budget 1/7 with arrows to step through a long document without scrolling.

  • Search up to 3 content keywords at once with Pro
  • Matching lines are shown under each result, so you can tell files apart before opening them
  • Drag a box over a PDF preview to zoom in up to 800% on drawings, tables, and small print

Built-in OCR · every plan

Scanned PDFs and photos are searchable too.

Find Text reads the text in scanned documents, screenshots, whiteboard photos, and images, so a signed contract or a photo of a receipt shows up like any other file. OCR is now free on every plan.

  • Scanned PDFs and images: JPG, PNG, HEIC, TIFF, and BMP
  • Recognized text is highlighted on the page in the preview
  • Text recognition runs on your Mac

Partial-word search

Find a word or number from any part.

Keywords of three or more letters or digits also match inside longer words, so 4401 finds PN-44017 in orders, packing slips, spreadsheets, and notes. End a word with * to match its start, so ap* finds apple and approval.

  • Works with English, Chinese, Japanese, and Korean text
  • Useful for part numbers, invoice numbers, codes, and names you only half remember

Narrow results fast

Combine file name, file type, and content.

Find "payment" only in PDFs, or notes named "2026" that mention "budget". With Pro, add exclude keywords to drop drafts or samples from the list.

  • File Name, Extension, Content, and Exclude fields work together
  • Open, Open With, Reveal in Finder, Show Path, and Copy Path from any result

Command line tool · Pro

Search from Terminal, scripts, and AI tools.

The find-text command, or the short ft, searches the same index as the app. Print names and paths, plain paths, or JSON with snippets and PDF page numbers.

  • Set up in Settings > Command Line Tool > Copy Setup Command
  • search, status, and update commands
  • The same filters as the app: --name, --ext, --exclude

FAQ

Questions, answered.

Is OCR included in the free plan?

Yes. Since version 1.2, built-in OCR for scanned PDFs and images is included on every plan, including Basic.

Do my files leave my Mac?

No. Find Text reads only the folders you add, builds its index on your Mac, and never uploads your files, document text, or search history. No account is needed.

Can I search part of a word or number?

Yes. Type 4401 to find PN-44017, or end a word with * to match its start, so ap* finds apple and approval. This works with English, Chinese, Japanese, and Korean text.

Can it search iCloud Drive?

Yes. Add an iCloud Drive folder like any other folder. Files that are stored only in the cloud need to be downloaded to your Mac before their text can be indexed.

How do I set up the command line tool?

With Pro, open Settings > Command Line Tool, turn it on, click Copy Setup Command, and paste the command into Terminal. Then run ft search followed by your keywords. See the command line guide for every option.

Is Find Text the same app as Quick Search File?

No. They are separate apps. Find Text searches the words inside your documents on Mac. Quick Search File is a different app for finding files by name. Find Text was previously listed on the App Store as "Quick Search Files & Find Text".
