Guide

How to search up to 3 keywords with colored highlights.

Each keyword gets its own color and match counter, so you can see where every term appears without reading the whole document.

Every keyword, its own color

Type your keywords in Content, separated by spaces or commas. Find Text lists the documents that contain all of them and highlights each keyword in a different color, in the result list and in the preview.

  • Basic: one content keyword.
  • Pro: up to 3 content keywords at once.

Step through matches

Above the preview, each keyword has a counter such as budget 1/7. Use its up and down arrows to jump to the previous or next match for that keyword, even in a long PDF or report.

The result list may show separate lines for different keywords, so a long paragraph doesn't hide later matches.

Zoom in on PDFs

In a PDF preview, drag a box over an area to zoom in on it, up to 800%. This helps with drawings, tables, and small print.

Choose strong keywords

  • Pick words that are likely to appear together in the document you need, such as a client, a project, and a topic.
  • If there are too many results, add a file type in Extension or part of the name in File Name.
  • With Pro, use Exclude to remove drafts, templates, or old versions that keep appearing.
