How to search 3 keywords with different colors.

Colored highlights help you compare several remembered terms without losing your place in a long passage.

Use three strong clues

Search up to three content keywords together. Choose terms that are likely to appear near the document you need, such as a person, company, project, topic, or phrase.

Scan by color

Different highlight colors make each keyword easier to spot in results and previews. This is useful when a paragraph contains multiple important clues.

Combine with file type

If the result list is too broad, add a file type filter such as PDF or Word. This keeps the colored keyword review focused on the formats you expect.

Exclude distractions

Use exclude terms to remove drafts, templates, or old versions when those files keep appearing in the result list.
