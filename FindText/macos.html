Workflow

From folder to answer in three steps.

Find Text is built for people with real document folders: project archives, research notes, client folders, manuals, invoices, scans, and reference material.

Add folders

Choose the Mac folders you want to search, including cloud-synced folders that are available locally through Finder.

Build or update

Let Find Text prepare those folders for fast local search. Refresh when files are added, removed, renamed, or changed.

Search and preview

Search by file name, file type, document content, and exclude words. Preview matching passages before opening the file.

Search fields

Combine the clues you already know.

Use one field for a broad search, or combine fields when you know the format, file name, and words inside the document.

File name and file type

Search remembered names, years, projects, clients, or document types, then narrow by formats such as PDF, Word, spreadsheet, presentation, text, or web files.

Content and exclude terms

Search for words inside documents and remove unwanted matches such as drafts, templates, archived copies, or unrelated versions.

3 colored content keywords

Search up to three content keywords together. Different highlight colors make each term easier to spot in results and previews.

Preview before opening

Review the matching passage first, then open the original file, reveal it in Finder, or copy its path.

Optical Character Recognition (OCR)

Make scanned words searchable.

Optical Character Recognition (OCR) helps Find Text search text that is visible in images but not selectable as normal document text.

Scanned PDFs

Search printed pages that were scanned as PDFs, including old paperwork, reports, forms, and manuals.

English newspapers and books

Find names, places, quotes, and topics inside English newspaper clippings, old book pages, and archival scans.

Photos and screenshots

Search text captured in phone photos, screenshots, receipts, notes, and images exported from other apps.
