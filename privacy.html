Privacy Policy

Quick Search File is built around local search. The app indexes folders and connected locations you choose so you can find files by filename, extension, folder path, and search terms.

Last updated: November 23, 2026

English日本語繁體中文

Scope of Data Collection

Quick Search File creates local indexes for file search. Depending on the features you use, the app may process filenames, file extensions, folder paths, file identifiers, file sizes, modified dates, selected folder information, search terms, index update status, app settings, subscription status, and related metadata needed to display search results.

The app does not collect your name, phone number, contacts, location information, or other personally identifiable information for advertising purposes.

Purpose of File Access

Quick Search File uses the iOS, iPadOS, or macOS file picker and platform permissions to let you actively authorize specific folders. Folder access is used only to read file names, file extensions, paths, and related metadata needed to build and update a search index.

OneDrive Access

If you choose to connect Microsoft OneDrive, Quick Search File uses Microsoft OAuth to access OneDrive file and folder information needed for search, indexing, result display, and user-directed file access.

Quick Search File uses OneDrive access only for file search features. The app does not use OneDrive access to create, edit, move, delete, or share your OneDrive files.

You can revoke OneDrive access through your Microsoft account permissions or remove the connected account in the app when that option is available.

Dropbox Access

If you choose to connect Dropbox, Quick Search File uses Dropbox OAuth and Dropbox API permissions such as account_info.read, files.metadata.read, and files.content.read.

Dropbox access is used to show the connected account, list folders, read file and folder metadata needed for search and indexing, display search results, and download a file only when you choose to open it from a search result. The app does not use Dropbox access to create, edit, move, delete, or share your Dropbox files.

You can revoke Dropbox access through your Dropbox connected-app settings or remove the connected account in the app when that option is available.

SSH Connections and Sign-In Details

If you set up NAS Index Acceleration (SSH) in Quick Search File for Mac, the app connects directly from your Mac to the NAS or Windows PC you specify and reads the file names, paths, modification times, and sizes needed to build the search index. It does not read file contents. The password or private key you enter is stored only in your Mac’s keychain, is used only to sign in to that server, and is never sent to the developer or any third party. When you remove a connection, sign-in details that no folder still uses are deleted from the keychain.

Data Protection Mechanisms

Quick Search File implements security measures to protect your sensitive data. Cloud provider API communications use encrypted HTTPS connections. File metadata used for search is processed and stored locally on your device. We do not upload, transfer, or store your files, search history, or sensitive file data on our own servers. Data stored locally on your device is protected by standard operating system security mechanisms such as iOS App Sandbox and macOS security features.

Data Storage and Use

Local index data and search settings are stored on your device. Quick Search File does not upload file contents, filenames, file paths, file identifiers, cloud drive metadata, search history, or local index data to any server or external location.

If the macOS Command Line Interface (CLI) is enabled, it uses the same app-authorized local index. CLI output may include filenames, paths, extensions, file sizes, and other metadata you request in text, paths-only, or JSON form.

Subscriptions and Payments

If you use in-app subscriptions, payment and subscription management are handled by the Apple App Store. Quick Search File may receive subscription status needed to unlock app features, but it does not obtain or store your credit card information.

Data Sharing

Quick Search File does not sell your personal information. Data may be shared only when needed to provide user-requested functionality, comply with law, protect security, process App Store subscriptions through Apple, operate hosting infrastructure, or when you explicitly export, copy, open, or share information yourself.

Data Deletion

You can delete the app to remove locally stored index data and settings. OneDrive access can be revoked from your Microsoft account permissions, Dropbox access can be revoked from your Dropbox connected-app settings, and related indexes can be removed or refreshed in the app where available.

Website Data

This website is a static product website hosted on GitHub Pages. Standard server logs or platform-level analytics may process basic request information such as IP address, browser, referring page, and request time for security, reliability, and hosting operations.

Policy Updates

This Privacy Policy may be updated due to app changes, OneDrive support, Dropbox support, NAS Index Acceleration (SSH), storage provider changes, subscriptions, platform requirements, or legal requirements. Updated versions will be posted on this page.

Contact

If you have questions about this Privacy Policy, please use the Quick Search File support page at https://quicksearchfile.com/support.html.

プライバシーポリシー

収集するデータの範囲

Quick Search Fileは、ファイル検索のために端末内で索引を作成します。利用する機能に応じて、ファイル名、拡張子、フォルダパス、ファイル識別子、ファイルサイズ、更新日時、選択したフォルダ情報、検索語、索引更新状態、App設定、サブスクリプション状態、および検索結果の表示に必要な関連メタデータを処理する場合があります。

本Appは、広告目的で氏名、電話番号、連絡先、位置情報、その他個人を識別できる情報を収集しません。

ファイルアクセスの目的

Quick Search Fileは、iOS / iPadOS / macOSのファイルピッカーおよびプラットフォーム権限を使用し、ユーザーが特定のフォルダを明示的に許可できるようにします。フォルダアクセスは、検索索引の作成と更新に必要なファイル名、拡張子、パス、および関連メタデータを読み取る目的のみに使用されます。

OneDriveへのアクセス

Microsoft OneDriveを接続する場合、Quick Search FileはMicrosoft OAuthを使用し、検索、索引作成、検索結果表示、およびユーザーが指示したファイルアクセスに必要なOneDriveのファイルとフォルダ情報へアクセスします。

Quick Search Fileは、OneDriveへのアクセスをファイル検索機能のためにのみ使用します。本Appは、OneDriveのファイルを作成、編集、移動、削除、共有するためにOneDriveアクセスを使用しません。

OneDriveへのアクセスは、Microsoftアカウントの権限設定、またはApp内で利用可能な場合は接続済みアカウントの削除によって取り消すことができます。

Dropboxへのアクセス

Dropboxを接続する場合、Quick Search FileはDropbox OAuthとaccount_info.read、files.metadata.read、files.content.readなどのDropbox API権限を使用します。

Dropboxアクセスは、接続アカウントの表示、フォルダ一覧、検索と索引作成に必要なファイルおよびフォルダのメタデータの読み取り、検索結果の表示、およびユーザーが検索結果からファイルを開いた場合のダウンロードにのみ使用されます。本Appは、Dropboxのファイルを作成、編集、移動、削除、共有するためにDropboxアクセスを使用しません。

Dropboxへのアクセスは、Dropboxの接続済みApp設定、またはApp内で利用可能な場合は接続済みアカウントの削除によって取り消すことができます。

SSH接続とログイン情報

Quick Search File for MacでNAS索引の高速化（SSH）を設定すると、本Appはお使いのMacから指定されたNASまたはWindowsパソコンに直接接続し、検索索引の作成に必要なファイル名、パス、変更日時、サイズを読み取ります。ファイルの内容は読み取りません。入力されたパスワードや秘密鍵はお使いのMacのキーチェーンにのみ保存され、そのサーバーへのログインにのみ使用されます。開発者や第三者に送信されることはありません。接続を削除すると、どのフォルダも使用していないログイン情報はキーチェーンから削除されます。

データ保護メカニズム

Quick Search Fileは、機密データを保護するためのセキュリティ対策を講じています。クラウドプロバイダAPIとの通信には暗号化されたHTTPS接続を使用します。検索に使用されるファイルメタデータは、お使いの端末内でローカルに処理および保存されます。ファイル、検索履歴、または機密ファイルデータを当社のサーバーにアップロード、転送、または保存することはありません。端末内にローカル保存されるデータは、iOS App SandboxやmacOSのセキュリティ機能などの標準的なオペレーティングシステムの保護機構によって保護されます。

データの保存と利用

ローカル索引データと検索設定は端末内に保存されます。Quick Search Fileは、ファイル内容、ファイル名、ファイルパス、ファイル識別子、クラウドドライブのメタデータ、検索履歴、またはローカル索引データを、いかなるサーバーまたは外部の場所にもアップロードしません。

macOSのCommand Line Interface (CLI)を有効にした場合、CLIは同じApp承認済みローカル索引を使用します。CLI出力には、ユーザーが要求したファイル名、パス、拡張子、ファイルサイズ、およびその他のメタデータがテキスト、パスのみ、またはJSON形式で含まれる場合があります。

App内サブスクリプションを利用する場合、支払いとサブスクリプション管理はApple App Storeによって処理されます。Quick Search Fileは機能のロック解除に必要なサブスクリプション状態を受け取る場合がありますが、クレジットカード情報を取得または保存しません。
