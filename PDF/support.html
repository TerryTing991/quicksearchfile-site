Last updated: September 14, 2026

System Requirements

PDF Pro requires macOS 14 or later and opens documents with the .pdf filename extension. Everything the app needs, including its OCR, is included; no internet connection or extra software is required.

Getting Started

  1. Choose Add PDF Files, press Command-O, or drag one or more PDF documents into the window.
  2. Select a document in the Documents list and use the page thumbnails, page number field, or navigation buttons to move through its pages. The zoom menu offers Fit Page, Fit Width, and fixed percentages.
  3. Use the search field to search the document text. Matching pages are added as OCR finishes; click a result to jump to the page and highlight the match.
  4. Click OCR beside the zoom controls, choose Text & Formula, Only Formula, or Table, then drag a rectangle around part of a page to recognize it as text, formulas, or a table.
  5. Add highlights, outline boxes, arrows, and text annotations, plus page bookmarks with notes, without changing the source document.
  6. Insert pages from other PDFs, rotate, reorder, or delete pages, then choose Save to update the original PDF or Save As to create a new one.
  7. Choose File > Export Flatten PDF to fix annotations into a new PDF, or File > Export to TIFF to convert open documents into multi-page TIFF files.
  8. Choose File > Print Document or press Command-P to print the current page, a range, or all pages.

Frequently Asked Questions

Does PDF Pro upload my documents or OCR text?

No. PDF rendering, text extraction, search, and OCR run locally on your Mac. Documents, page images, OCR results, search terms, highlights, bookmarks, and notes are not uploaded to a PDF Pro server for processing.

Which file types can I open?

PDF Pro opens PDF documents. You can open multiple documents in the same workspace and switch between them from the Documents list. Each document remembers its last viewed page, and open documents are restored on the next launch when their source files are still available.

Why can the first full-document search take time?

PDF Pro combines text embedded in the PDF with a local OCR index built from the page images, so result highlights match what you see in the viewer. Large, high-resolution, or scanned documents can take longer on the first search. The current page is handled first, results appear as pages finish, and later searches reuse the saved index.

What should I do if search finds no results?

Wait until the OCR progress finishes, then try a shorter keyword. Search ignores letter case, accents, and spaces. Recognition quality depends on scan resolution, contrast, typeface, language, and page orientation. PDF Pro supports English and Chinese, including horizontal text and vertical Chinese text, but unclear scans may still produce incomplete results.

How does area OCR for formulas and tables work?

Click OCR beside the zoom controls, pick a mode, and drag a rectangle on one page. When recognition finishes, a result window shows one editable document containing ordinary text, LaTeX formulas, and Markdown tables, with a live preview. Use Select All or Copy All to paste the result into another document. Recognition runs entirely on your Mac.

Which OCR mode should I choose?

Text & Formula, the default, reads sentences and equations together and does not look for tables. Choose Only Formula when the area holds nothing but formulas, including one equation that runs over several lines. Choose Table when the whole area is one table. A matrix equation and a table can look alike on the page, so the app asks rather than guessing. Complex equations and tables should still be compared with the PDF and corrected before use.

Does page editing change my original PDF file?

Not until you save. Inserting pages from other PDFs, rotating, reordering, and deleting pages do not touch the original file. Choose File > Save or press Command-S to update the original PDF with the edited pages, or File > Save As to create a new PDF while keeping the original unchanged. If you remove a document, close the window, or quit with unsaved page edits, PDF Pro offers Save, Cancel, or Don't Save.

What happens to annotations when I rotate a page?

Rotate Left and Rotate Right turn every selected page by 90 degrees. Annotations on those pages are removed before the rotation; bookmarks and bookmark notes remain.

Where are highlights, bookmarks, and notes stored?

They are stored locally in PDF Pro app data and remain separate from the source PDF. Save and Save As do not embed them. Printing includes annotations when Print Annotations is selected, and TIFF export includes them when Export Annotations is selected. Use File > Export Flatten PDF to create a new PDF with the annotations fixed into its pages; flattened annotations are visible in other PDF software but can no longer be moved or deleted individually. Removing a document from the workspace does not delete the source file or its saved annotations.

How does TIFF export work?

File > Export to TIFF lists every open PDF. Select the files you want, choose Compact, Balanced, or High quality, decide whether to include annotations, and pick an output folder. Each PDF becomes one multi-page .tiff file with the same base filename, following the current page order. Two documents that would produce the same filename cannot be exported in the same batch. TIFF is an image format, so searchable text, links, and forms are not included.

Why is a page or thumbnail still loading?

Large or high-resolution pages may need extra time the first time they are shown. Jumping far into a long document can also start thumbnail and page rendering work that has not yet been cached. Wait for the page to finish; revisiting it is usually faster.

How do I print only the current page?

Choose File > Print Document or press Command-P, then leave Pages set to Current Page in the macOS print panel. You can also choose Range or All Pages, and clear Print Annotations to print only the original page content. Printing follows the current page order, and each page is scaled proportionally to the printable area; final margins depend on the selected printer, paper size, and original page proportions.

What should I do if a document no longer opens after relaunch?

Confirm that the source file still exists and that your macOS account can read it. If the file was moved, renamed, or stored on a disconnected drive, open it again from its new location.

Keyboard Shortcuts

  • Command-O: Add PDF files
  • Command-Shift-I: Insert pages from another PDF
  • Command-S: Save changes to the original PDF
  • Command-Shift-S: Save As a new PDF
  • Command-P: Open the print panel
  • Command-Control-S: Hide or show the sidebars
  • Command-?: Open the in-app help
  • Delete: Delete the selected annotation, or the selected pages when no annotation is selected
  • Escape: Finish editing an annotation
