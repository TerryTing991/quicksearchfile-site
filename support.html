Frequently Asked Questions

Why do I need to authorize folders?

Quick Search File needs permission before it can index file names and extensions. On iOS and iPadOS, folder access is granted through the system Files picker. On macOS, access is handled by macOS permissions and app settings.

How does OneDrive support work?

When OneDrive support is enabled, Quick Search File uses Microsoft OAuth to access OneDrive file and folder information needed for search and indexing. The app does not create, edit, move, delete, or share your OneDrive files.

How does Dropbox support work?

When Dropbox support is enabled, Quick Search File uses Dropbox OAuth to read account info, file and folder metadata, and file content only when you open a result. The app does not create, edit, move, delete, or share your Dropbox files.

Does the app upload my local search index?

No. Local index data and search settings are stored on your device and are not uploaded to a Quick Search File server.

What should I do if search results are outdated?

On iOS and iPadOS, refresh or update the index in the app after adding, deleting, moving, or renaming many files. On macOS, Quick Search watches your indexed folders: when files change, Update Index becomes available, and with Pro and automatic updates on, the index updates by itself. Changes made by other computers on network drives (NAS, SMB) are not reported to your Mac, so use Update Index or ⌘R for those folders. Cloud provider sync state can also affect whether files are available for indexing.

The ⌥⌘S shortcut doesn't open the quick search panel on my Mac. What can I do?

macOS or another app may already use the same keys. Choose another shortcut in Quick Search › Settings › Quick Search Panel, or turn off the other one. You can also open the panel from the Quick Search menu bar icon.

Why can't I add Macintosh HD or my home folder with Basic?

Basic can use up to 3 folders, but it can't add all of Macintosh HD, the Users folder, or your home folder, because each contains almost everything on your Mac. Choose folders inside them instead, such as Documents or Downloads. External and network drives can be added from their top folder. Pro can add these folders and more.

Why can some cloud folders not be indexed?

Some storage providers, app folders, shared drives, read-only locations, or cloud-only files may restrict third-party access. Provider permissions and local availability can affect results.

How do I revoke OneDrive or Dropbox access?

You can revoke OneDrive access from your Microsoft account permissions and Dropbox access from your Dropbox connected-app settings. After revoking access, remove or refresh related indexes in the app where available.

よくある質問

なぜフォルダの許可が必要ですか？

Quick Search File がファイル名と拡張子を索引化するには権限が必要です。iOS / iPadOS では、フォルダアクセスはシステムの Files ピッカーを通じて許可されます。macOS では、macOS の権限と App 設定によってアクセスが管理されます。

OneDrive 対応はどのように動作しますか？

OneDrive 対応を有効にすると、Quick Search File は Microsoft OAuth を使用し、検索と索引作成に必要な OneDrive のファイルとフォルダ情報へアクセスします。本Appは、OneDrive のファイルを作成、編集、移動、削除、共有しません。

Dropbox 対応はどのように動作しますか？

Dropbox 対応を有効にすると、Quick Search File は Dropbox OAuth を使用し、アカウント情報、ファイルとフォルダのメタデータ、およびユーザーが検索結果から開いたファイル内容のみを読み取ります。本Appは、Dropbox のファイルを作成、編集、移動、削除、共有しません。

App はローカル検索索引をアップロードしますか？

いいえ。ローカル索引データと検索設定は端末内に保存され、Quick Search File のサーバーへアップロードされません。

検索結果が古い場合はどうすればよいですか？

iOS / iPadOS では、ファイルを大量に追加、削除、移動、名前変更した後に App 内で索引を更新してください。macOS では、Quick Search が索引対象のフォルダを監視しています。ファイルが変わると「索引を更新」が使えるようになり、Pro で自動更新をオンにしている場合は索引が自動で更新されます。ほかのコンピュータがネットワークドライブ（NAS、SMB）上で行った変更は Mac に通知されないため、それらのフォルダでは「索引を更新」または ⌘R を使ってください。クラウドプロバイダの同期状態も、ファイルが索引化可能かどうかに影響する場合があります。

Mac で ⌥⌘S を押してもクイック検索パネルが開きません。

macOS やほかの App が同じキーを使用している可能性があります。Quick Search の設定 › クイック検索パネル で別のショートカットを選ぶか、もう一方をオフにしてください。メニューバーの Quick Search アイコンからもパネルを開けます。

Basic で「Macintosh HD」やホームフォルダを追加できないのはなぜですか？

Basic では最大 3 つのフォルダを使えますが、「Macintosh HD」全体、「ユーザ」フォルダ、ホームフォルダは追加できません。どれも Mac のほぼすべてを含むためです。「書類」や「ダウンロード」など、その中のフォルダを選んでください。外部ドライブやネットワークドライブは最上位のフォルダから追加できます。Pro ではこれらのフォルダも追加でき、フォルダ数も増やせます。

一部のクラウドフォルダを索引化できないのはなぜですか？

一部のストレージプロバイダ、App フォルダ、共有ドライブ、読み取り専用の場所、またはクラウド上のみのファイルは、第三者Appからのアクセスが制限される場合があります。プロバイダの権限とローカルでの利用可能性が結果に影響します。

OneDrive、Dropbox へのアクセスを取り消すには？

OneDrive へのアクセスは Microsoft アカウントの権限設定から、Dropbox へのアクセスは Dropbox の接続済みApp設定から取り消せます。取り消し後、App 内で関連する索引を削除または更新してください。

常見問題

為什麼需要授權資料夾？

Quick Search File 需要權限才能建立檔案名稱與副檔名索引。在 iOS / iPadOS 上，資料夾存取會透過系統 Files 檔案選擇器授權。在 macOS 上，存取權限由 macOS 權限與 App 設定管理。

OneDrive 支援如何運作？

啟用 OneDrive 支援時，Quick Search File 會使用 Microsoft OAuth，以存取搜尋與索引所需的 OneDrive 檔案與資料夾資訊。本 App 不會建立、編輯、移動、刪除或分享您的 OneDrive 檔案。

Dropbox 支援如何運作？

啟用 Dropbox 支援時，Quick Search File 會使用 Dropbox OAuth，以讀取帳號資訊、檔案與資料夾 metadata，以及僅在您從搜尋結果開啟檔案時讀取該檔案內容。本 App 不會建立、編輯、移動、刪除或分享您的 Dropbox 檔案。

App 會上傳我的本機搜尋索引嗎？

不會。本機索引資料與搜尋設定會儲存在您的裝置上，不會上傳到 Quick Search File 伺服器。

搜尋結果不是最新時該怎麼辦？

在 iOS / iPadOS 上，大量新增、刪除、移動或重新命名檔案後，請在 App 內重新整理或更新索引。在 macOS 上，Quick Search 會監看已加入索引的資料夾：檔案有變動時，「更新索引」會變成可以按；Pro 開啟自動更新時，索引會自動更新。其他電腦在網路磁碟（NAS、SMB）上做的變動不會通知您的 Mac，這些資料夾請使用「更新索引」或 ⌘R。雲端服務的同步狀態也可能影響檔案是否可被索引。

在 Mac 上按 ⌥⌘S 沒有打開快速搜尋視窗，該怎麼辦？

可能是 macOS 或其他 App 已經使用這組按鍵。請在 Quick Search 的設定 › 快速搜尋視窗 換一組快捷鍵，或關閉另一邊的設定。您也可以從選單列的 Quick Search 圖示打開快速搜尋。

為什麼 Basic 無法加入「Macintosh HD」或個人專屬資料夾？

Basic 最多可以使用 3 個資料夾，但無法加入整個「Macintosh HD」、「使用者」資料夾或您的個人專屬資料夾，因為它們幾乎包含整台 Mac。請選擇裡面的資料夾，例如「文件」或「下載」。外接硬碟與網路磁碟可以從最上層資料夾加入。Pro 可以加入這些資料夾，也能使用更多資料夾。

為什麼有些雲端資料夾不能索引？

部分儲存空間提供者、App 資料夾、共享雲端硬碟、唯讀位置或僅存在雲端的檔案，可能會限制第三方 App 存取。提供者權限與本機可用狀態都可能影響結果。

如何撤銷 OneDrive 或 Dropbox 存取？

您可以從 Microsoft 帳號權限設定撤銷 OneDrive 存取權限，並從 Dropbox 的已連接 App 設定撤銷 Dropbox 存取權限。撤銷後，請在 App 內可用時移除或重新整理相關索引。
