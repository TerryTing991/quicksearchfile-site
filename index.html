Questions

Quick Search File in short.

What the app does, what it costs, where it runs, and how it compares with other Mac file search tools.

What is Quick Search File?

Quick Search File is a file search app for Mac, iPhone, and iPad. It builds a local filename index of the folders you choose, then finds files by name and extension, and on Mac by folder name, in milliseconds. On Mac, press ⌥⌘S in any app to open a quick search panel.

Does it search inside files?

No. Quick Search File searches file and folder names only and does not read file contents. To search the words inside documents, use Find Text: File Content Search, a separate Mac app.

Is Quick Search File free?

On Mac, Basic is free: up to 3 folders, one filename keyword with an optional extension and folder filter, and the ⌥⌘S quick search panel. Pro adds more folders, multiple keywords with AND / OR matching, extension-only search, automatic index updates, faster network drive indexing, and the qs command line tool. Pro is a monthly or yearly subscription, or a one-time Lifetime Pro purchase. On iPhone and iPad, the app includes 3 free searches, then needs a subscription.

Which folders and cloud services can it index?

On Mac: any folder you add through Finder, including external drives, network drives (NAS, SMB), and cloud-synced folders available on your Mac, such as OneDrive, Google Drive, Dropbox, and iCloud Drive. On iPhone and iPad: folders you authorize through the Files picker, plus OneDrive and Dropbox accounts you connect.

How is it different from Spotlight?

Spotlight searches your whole Mac, including apps, file contents, and the web. Quick Search File searches only the names of files in the folders you choose. You can combine keywords with AND / OR, filter by extension and folder name, and run the same search from Terminal.

What is Quick Search File an alternative to?

On AlternativeTo, Quick Search File is listed as an alternative to Spotlight, Raycast, Alfred, EasyFind, Find Any File, ProFind, and HoudahSpot. It does one job: finding files by name in the folders you index.

Can AI assistants and scripts use it?

Yes. With Pro on Mac, the qs command line tool searches the same local index from Terminal. It prints paths only for shell pipelines, or JSON with name, path, extension, root folder, and file size for AI assistants and automation. Example: qs search report --ext pdf --json --limit 10.

Is my data private?

Yes. The index stores file names, folder relationships, extensions, dates, and sizes on your device. File contents are not read, and the index and your search history are not uploaded. The app itself needs no account or registration.

How fast is it?

In a stress test with 100,000 generated files, a search with combined filename terms and an extension filter averaged 4.952 ms on Mac and 6.731 ms on iOS. Actual times vary by device, storage, and index size. See the performance data.

What do I need to run it?

A Mac with macOS 13 or later, or an iPhone or iPad with iOS or iPadOS 17 or later. The app is available in English, Japanese, and Traditional Chinese, and is a free download on the App Store.
