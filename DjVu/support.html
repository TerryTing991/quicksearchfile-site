Support

Need help with Mac DjVu? Send a clear report and we will use it to diagnose document opening, page display, OCR search, annotations, editing, saving, or printing as quickly as possible.

Last updated: August 12, 2026

System Requirements

Mac DjVu requires macOS 14 or later and opens documents with the .djvu or .djv filename extension.

Getting Started

  1. Choose Add DjVu Files, press Command-O, or drag one or more DjVu documents into the app.
  2. Select a document and use the thumbnail list, page number field, or navigation buttons to move through its pages.
  3. Use the search field to search available embedded text together with a local Vision OCR index. Results are added as pages finish processing.
  4. Use highlights, page bookmarks, and bookmark notes to mark important content without changing the source document.
  5. Reorder or remove pages in the workspace, then choose Save As to create a new DjVu file while keeping the original unchanged.
  6. Choose Print or press Command-P to print the current page, all pages, or a page range.

Frequently Asked Questions

Does Mac DjVu upload my documents or OCR text?

No. DjVu decoding, page rendering, text extraction, search, and OCR run locally on your Mac. Documents, page images, OCR results, search terms, highlights, bookmarks, and notes are not uploaded to a Mac DjVu server for processing.

Which file types can I open?

Mac DjVu opens DjVu documents with the .djvu or .djv filename extension. You can open multiple documents in the same workspace and switch between them from the Documents list.

Why can the first full-document search take time?

Mac DjVu combines available text embedded in the document with an on-device Vision OCR index. OCR analyzes rendered page images so result highlights align with the content displayed in the viewer, even when embedded document coordinates are inaccurate. Large, high-resolution, or image-only documents can take longer on the first search. Results appear incrementally as pages finish processing, and later searches can reuse the saved OCR index.

What should I do if search finds no results?

Wait until the OCR progress finishes, then try a shorter keyword. Recognition quality depends on scan resolution, contrast, font, language, and page orientation. Mac DjVu supports English and Chinese, including left-to-right horizontal text and vertical Chinese text, but unclear scans may still produce incomplete results.

Does page editing change my original DjVu file?

No. Reordering and deleting pages in the workspace are non-destructive. The source document remains unchanged. Mac DjVu creates an edited copy only when you choose Save As and select a destination.

Where are highlights, bookmarks, and notes stored?

They are stored locally in Mac DjVu app data and remain separate from the source document. Removing a document from the current workspace does not delete the source file. Deleting the app's local data can remove saved OCR indexes and annotations.

Why is a page or thumbnail still loading?

Large or high-resolution pages may need extra time for their first decode. Jumping far into a long document can also start thumbnail and page rendering work that has not yet been cached. Wait for the page to finish, then try it again; later viewing is usually faster.

How do I print only the current page?

Choose Print or press Command-P, then leave Pages set to Current Page in the macOS print panel. You can also choose All or enter a page range. Mac DjVu scales each page proportionally to the paper's printable area; final margins depend on the selected printer, paper size, and original page proportions.

Where is my edited document saved?

Save As writes a new DjVu file to the destination you select in the macOS save panel. If you cannot find the file, check the folder and filename chosen during the save operation.

What should I do if a document no longer opens after relaunch?

Confirm that the source file still exists and that your macOS account can read it. If the file was moved, renamed, or stored on a disconnected drive, open it again from its new location.

Keyboard Shortcuts

  • Command-O: Add DjVu files
  • Command-Shift-S: Save an edited copy
  • Command-P: Open the print panel
  • Command-?: Open the in-app help
